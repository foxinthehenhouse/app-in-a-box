1. The agent is in the interview phase: it asks about the product (who it's for and
   the problem, or the core loop / the one thing a runner does most often), seeded
   by "habit tracker for trail runners" rather than asking "what's your idea?" cold.
2. It reflects the idea back in its own words, or builds on it, before or while asking.
3. It does NOT ask about things it can find out itself (tool versions, whether a CLI
   is installed, which command to run).
4. It asks at most 3 questions in this turn, not a long form.
5. It doesn't write code or scaffold anything yet.
